# BOGOBOT

**ART.IS.YOU / ARTISTIC RESEARCH / HUMAN AGENCY**

What happens to the human when non-human intelligence becomes involved in producing knowledge, memory, images and decisions?

BOGOBOT is an artistic research project within **ART.IS.YOU**. It examines how human subjectivity and agency change when intelligence is no longer exclusively human. Technology is not the final subject of the project; it is the infrastructure of a deeper cultural and anthropological shift.

### Research territories

`01 AGENCY` · `02 INTELLIGENCE` · `03 POWER` · `04 TRUTH` · `05 REALITY`  
`06 PREDICTION` · `07 IDENTITY` · `08 MEMORY` · `09 AUTHORSHIP` · `10 BELIEF`  
`11 ERROR` · `12 LANGUAGE` · `13 LIFE` · `14 DEATH` · `15 GOD`

These territories form one research system rather than a set of independent themes.

### Research form

**Network / Archive / Reader**

BOGOBOT brings together a network of interconnected concepts and texts, historical and fictional traces, and reader experiences. Its underlying question is not what AI can generate, but **what happens to human agency when machines participate in defining reality**.

### This repository

This repository contains an earlier published static implementation of BOGOBOT. Its checked-in code and documentation must **not** be confused with the newer graph and Reader candidates developed separately. The description below refers to this repository's own historical implementation, not the current full scope of the project.

<details>
<summary>Repository implementation notes · earlier prototype</summary>

The existing repository README documented a local rhizomatic navigation prototype with 52 graph nodes, 41 page-only records, 93 records in total, progressive network disclosure, local semantic continuations, a random-node route, search, history, image restoration and machine-generated audio signals.

To explore the checked-in prototype, open `index.html` and use `ENTER THE NETWORK`. Audio begins disabled and can be enabled through `SIGNAL: OFF`.

The repository also contains a linear BOOKS reader in `books/`, with build and validation commands:

```bash
npm run build:books
npm run validate:books
```

The earlier repository documentation specifies the six-part route `P → −I → 00 → I → II → ∞`. This is historical repository documentation, **not** a statement about the approved FROZEN Reader in the later project.

</details>
